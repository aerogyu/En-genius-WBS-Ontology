## 1. 산출물·투입인력 편집

- 상세 패널 '✎ 고치기' 에 **투입인력**(숫자)·**산출물**(글자, 여러 개는 `;` 로) 칸. 하위 업무와 요약(묶음) 모두 — 산출물은 주로 Lv5 에 적혀 있어서.
  날짜 계산과 무관하다 (날짜 바뀐 업무 0). 요약의 기간·시작·Man Hours 는 전처럼 못 고친다 (아래에서 올라옴).
- 서버: `edit.py` 의 고칠 칸에 `staff`·`deliverables`. 권한·겹침 거절·이력은 다른 칸과 같다 (이력 이름 '투입인력'·'산출물').
  산출물은 글자 하나로 받아 `;`·줄바꿈·설정의 `deliverable_split` 로 나눈 뒤, **그 칸이 적혀 있던 모양**으로 다시 적는다
  (줄바꿈으로 나눠 적던 칸은 줄바꿈, 아니면 첫 구분자 — 기본 `, `). 50개·한 개 300자까지.
- 판 비교: 요약 줄과 비교 엑셀에 '투입인력'·'산출물' 이 바뀐 업무 수.
- 파일 모드: 변경 목록에 `{"field": "deliverables" | "staff", "no": 번호, "to": 값}` → `apply.bat` 이 원본 사본의 그 칸만 고친다.

## 2. 찾기 — 늘 보이는 칸

- ① 탭 윗줄 오른쪽에 `업무 찾기` 칸 (조작 줄 높이는 그대로 — 1366×768 에서 그림 시작 161px 그대로). `/` 키로 바로 입력, `Enter` = 첫 결과, `Esc` = 닫기.
- 고르면 **그 업무가 든 묶음으로 들어가 그 업무를 고른다** (묶음을 고르면 그 안으로). 왼쪽 WBS 구조 안의 찾기 칸도 같은 규칙.
- 낱말마다 `번호 같음 · WBS 코드 앞부분 · 이름이나 위 묶음 이름에 들어 있음` — 띄어 쓴 낱말이 **모두** 맞아야 한다.
  같은 이름이 구성품마다 반복되므로 `HPC 성능`, `HPC 기본설계 성능` 처럼 좁힌다.
- 순서: 번호·WBS 가 꼭 맞음 → 이름이 꼭 같음 → 이름에 들어 있음 → 위 묶음 이름만 맞음, 그 안에서 얕은 레벨 먼저. 40개까지 보이고 `1,828개 중 40개` 로 알려 준다.

## 3. 간트 — 고를 때 다시 그리지 않기

- 전에는 행을 누를 때마다 간트 전체(표·막대·선)를 새로 그렸다. 이제 **고른 것만 바뀔 때는 행 강조·막대 색·선만** 고친다
  (`ganttPaint` — 선은 `<g id="gEdges">` 한 덩어리만 다시).
- Ctrl+휠 확대는 행이 1,500개를 넘으면 휠 사건을 모아 한 번만 다시 그린다.
- 다른 탭(③④)에서 가정 편집을 고친 뒤 ① 로 돌아오면 간트를 다시 그린다 (전에는 다음 조작 때까지 옛 날짜).
- 그대로인 것: Lv6 전체를 **처음 펼 때·확대할 때**는 여전히 약 2초 (보이는 행만 그리는 방식은 하지 않았다 — 표·눈금 틀 고정과 같이 손봐야 해서 따로).

## 4. 저장 되돌리기 — 설계안 (Leo 확인 대기)

**왜**: 일정 옮기기 한 번으로 수천 업무가 움직인다. 지금 되돌릴 길은 ① 반대로 다시 고치기 (당긴 뒤 다시 늦추면 원래와 달라질 수 있고, 선행·줄 편집은 손으로 못 맞춤)
② 서버를 끄고 백업으로 통째 복구 (그 사이 다른 사람이 한 일도 사라짐) 뿐이다.

**제안 — 저장 한 건을 되돌린다** (DB 비유: 입력 칸이 표, 날짜는 뷰. 표의 그 줄들만 저장 전 값으로 되돌리고 뷰를 다시 계산)

- 저장할 때마다 **바뀌는 줄의 저장 전 모습**을 DB 가 스스로 남긴다 (SQLite 트리거 — 칸 고치기·줄 편집·일정 옮기기 어느 길로 저장해도 빠짐없이).
  남기는 것 = 입력 칸(이름·기간·시작 하한·MH·투입인력·산출물·위치·삭제 표시)과 그 업무의 선행. 날짜는 남기지 않는다 — 되돌린 뒤 다시 짠다.
- **되돌리기** = 그 저장이 건드린 줄을 저장 전 값으로 → 날짜 다시 짜기 → 이것도 **새 저장 한 건**으로 이력에 남는다 ('#12 를 되돌림'). 지우는 이력은 없다.
- **마지막 저장은 언제나** 되돌릴 수 있다. 그 앞의 저장은 **뒤의 저장이 같은 업무를 건드리지 않았을 때만** (건드렸으면 거절하고 그 목록을 보여 줌 — 지금의 '겹침 거절' 과 같은 규칙).
- 화면: ④ 탭 '최근 저장' 과 업무별 이력의 각 줄에 `되돌리기` → 미리 계산(날짜 바뀌는 업무 수 · 사업 완료 변화) → 확인 → 저장.
- 줄 편집(추가·삭제·옮기기·풀기)도 같은 방식으로 되돌린다. 추가한 줄은 '지움' 으로 돌아간다 (번호를 다시 쓰지 않으려고 — 지금 삭제와 같음).
